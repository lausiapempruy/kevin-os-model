# Security Policy

## Scope

This repository may contain prompts, instructions, documentation, and related text resources. It is not a place to publish credentials or private operational data.

## Reporting a concern

Do not open a public issue for a report that contains a secret, private data, or a potentially exploitable issue. Contact the repository owner through the contact method available on their GitHub profile and share only the minimum details needed to understand the concern.

Please include the affected path or commit, the impact you observed, and a safe way to reproduce the issue if applicable.

## Sensitive data

Never commit API keys, passwords, access tokens, private conversations, or personal information without explicit permission. If a secret is committed, removing it from the latest version may not remove it from Git history; revoke or rotate the credential first.

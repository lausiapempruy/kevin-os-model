# Support

## Questions and usage help

- Read the resource's own documentation first.
- Search existing [issues](https://github.com/lausiapempruy/kevin-os-model/issues).
- For reproducible bugs, open an issue and include the file path, model or product used, steps to reproduce, and the behavior you expected versus what happened.
- For proposals, explain the use case and why existing resources do not cover it.

## What to include

Share only information needed to reproduce the problem. Remove API keys, account identifiers, private conversations, and other sensitive details.

## Important limitation

AI model outputs can vary by model version, product settings, and context. This repository cannot guarantee identical behavior across ChatGPT, Claude, Grok, or other platforms.
